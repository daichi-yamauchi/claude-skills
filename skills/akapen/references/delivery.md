# シートの届け方 — ローカルとクラウドの 2 経路

akapen で環境に依存するのは **HTML を人のブラウザに届ける 1 箇所だけ**。ソースの書式・build・試問・回答の形 (`reply-format.md`) はどちらでも同じ。
3 モード (標準・指摘・添削) 共通。

## どちらか判断する

| 状況 | 経路 |
|---|---|
| 人の Mac 上で動いている (ローカルの Claude Code) | **A. file://** |
| クラウドのセッション・sandbox・ssh・コンテナ。人がこの機械のファイルを開けない | **B. Artifact で公開** |

判断材料は「`open` が通るか」ではなく「**人がこの機械のファイルを開けるか**」。`open` が無いだけの環境でも、人が同じ Mac にいれば A で足りる (絶対パスを渡す)。

## A. ローカル — file:// で開く

```bash
python3 "<skill>/assets/build.py" ./akapen/<topic>-<NN>.akapen.md -o ./akapen/<topic>-<NN>.html
open ./akapen/<topic>-<NN>.html      # Linux: xdg-open / Windows: cmd /c start ""
```

`open` が無ければ絶対パスと `file://` URL を提示して人に開いてもらう。モック (`mock:`) は `file://` 絶対 URL のボタンになる。

## B. クラウド — Artifact で公開する

```bash
python3 "<skill>/assets/build.py" ./akapen/<topic>-<NN>.akapen.md -o ./akapen/<topic>-<NN>.html --hosted
```

`--hosted` を付けると、モックのリンクが `file://` ではなく相対パスになる。付け忘れるとモックのボタンが開けないリンクになる (モックが無いシートでは差は出ない)。

次に `Artifact` ツールで公開する。

- `action: "publish"`、`file_path` はビルドした HTML、`favicon: "✎"`
- `description` はシートの結論を 1 文
- **モックがあるときは `files` に一緒に渡す** (`{"mock/index.html": "./akapen/mock/index.html"}` のように、シートが参照する相対パスをキーにする)
- 返ってきた URL を人に伝える。人はブラウザで開いて回答し、[貼り付ける文章を作る] で出た文章をそのまま貼り戻す

**再往復 (`-02`)** は新しいシートなので、`url` を渡さず新しく publish する (`-01` のページは証跡として残す)。同じシートを直して出し直すときだけ、同じ会話でもう一度 publish すれば同じ URL が更新される。

**確認できていること** (2026-09-24 実測): フォント・図の実測レイアウト・押し下げ・赤丸・表・色は公開後も同じに出る。localStorage の下書きはアーティファクトごとの origin に保存される。

**自動コピーは公開ページでも通る** (2026-09-24 実測。Artifact の iframe で「✓ コピーしました」が出た)。拒否された環境では文章が自動で選択状態になるので、人はそのままコピーすればよい。

**スマホでは図だけが横スクロールになる。** 画面が図より狭いときは縮めて収めるが、文字が 9px を下回る手前で打ち止めにして、あふれた分は図の中で横スクロールさせる (縮め切ると全体図の文字が 6px まで落ちて読めない)。本文・表・問いカードは縦に収まる。
**図を広くしすぎない。** `w=720` の全体図はスマホで 1.5 画面ぶんの横スクロールになる。スマホでも見る前提なら、全体図を 2 枚に割るか `w` を 560 前後に抑える。

## 人への案内文 (B)

```
シートを公開しました。ブラウザで開いてください (スマホでも開けます):
  <URL>
- 問いごとのカードで答えてください。推奨の案があらかじめ選んであるので、推奨で良ければそのままで構いません
- まだ決めたくない問いは「選択を解除」してください。推奨では確定せず、次の往復でもう一度聞きます
- 決める前に聞きたいことがあれば「保留」を選んで書いてください
- 最後に [貼り付ける文章を作る] を押すとクリップボードに入るので、このチャットに貼ってください
```

## 何が外に出るか

公開ページは非公開 (リンクを知っていて、かつ本人のアカウントで開ける人だけ) だが、**シートの中身はこの機械の外に出る**。シートにはクライアント名・`file:line`・スクショ (data URI) が載る。
外に出せない題材では、絵の要る問いを落として chat の問いだけで回すか、その論点をローカルで作業するときまで持ち越す。判断はユーザーに聞く。

消すときは `action: "delete"` に URL を渡す。**削除はユーザーが頼んだときだけ**行い、勝手に消さない。

## 指摘モード・添削モード

どちらも出力は自己完結の HTML 1 枚なので、同じ 2 経路がそのまま使える。
添削モードは `build-sheet.py` に `--hosted` が無いが、モックの概念が無いので差は出ない。公開してリンクを渡すだけでよい。
