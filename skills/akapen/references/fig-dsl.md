# 図の DSL — fig / seq / svg / shot

原則: **文字は HTML、線は SVG**。箱の中の文章はブラウザが折り返すのではみ出さない。
箱の**高さと線の座標は書かない**。読み込み時に JS が箱の実際の高さを測り、被る行を押し下げ、矢印を箱の縁から引き直す (`assets/fig-layout.js`)。
図の幅より画面が狭いときは全体を縮小する。

## fig — 箱と矢印

````
```fig <id> [w=720] [fs=11]
title: 図の中の 1 行目 (主張)
caption: 図 N — 何を見るか: …
node <id> <x> <y> <幅> [red] [dashed] [zone] [in=<zoneId>] | 見出し
  本文の行 (字下げで続ける。折り返しは自動)
  !赤の行 (提案・論点)
  `等幅の行` (パス・URL・コード)
note <id> <x> <y> <幅> | 枠なしの注記 (本文の行も同じ書式)
edge <a>:<辺>[:<位置>] -> <b>:<辺>[:<位置>] [red] [dashed] [noarrow] [straight|curve|wrap] ["ラベル"]
mark <番号> <nodeId> <dx> <dy>
axis <x1> <y> <x2>
dot <x> <y> [red]
vline <x> <y1> <y2> [red] [dashed]
hline <x1> <y> <x2> [red] [dashed]
bars <x> <基線y> <幅> <間隔> <h1,h2,h3,…> [red]
```
````

### node / note

- `x y` は箱の左上、`幅` は px。図の幅 (`w`) は既定 720 (本文幅)。A/B 対比の小図は `w=360 fs=10.5`
- **スマホでも見るなら `w` を 560 前後まで抑える。** 画面が図より狭いと縮小されるが、文字が 9px を下回る手前で打ち止めになり、あふれた分は図の中で横スクロールになる。`w=720` はスマホで 1.5 画面ぶん横に流れる
- `red` = 提案・変更の箱 (淡赤地に赤枠、見出しは赤太字)。`dashed` = 任意・条件付きの箱 (赤の点線枠)。現状は無彩色 (何も付けない)
- `zone` = 他の箱を囲む枠。中の箱に `in=<zoneId>` を付ける。zone の高さは中身に合わせて伸び、zone が押し下げられれば中身も動く
- 見出しの `!` は赤 (`| !JST 0:00`)。本文の行頭 `!` も赤。`` `…` `` は等幅
- `note` は枠なし (時間軸のラベル、図の脚注)。押し下げの対象には含まれる
- 座標は「図の中で上から下・左から右」に置く。同じ `y` の箱は 1 行として扱い、行の中で最も押し下げが要る箱に合わせて揃う

### edge

- `<辺>` は `l` `r` `t` `b`。`<位置>` は辺の上の 0〜1 (省略 0.5 = 中央)。例 `ae:b:0.27` = ae の下辺の左から 27%
- 経路: 省略 = 直交 (直線・L 字・コ の字を自動)。`straight` = 斜めの直線。`curve` = 曲線 (辺の法線方向に膨らむ)。`wrap` = 行末から次の行頭へ戻る (右へ出て、下がって、左へ戻り、入る)
- `red` = 赤の線と矢じり (提案の流れ)。`dashed` = 破線。`noarrow` = 矢じりなし (工程の連結など)
- `"ラベル"` は線の中ほどに白縁取りで乗る (赤の線なら赤字)

### mark (赤丸 ①②③)

`mark 1 browser 156 54` = browser の左上から (156, 54) に「1」の赤丸。箱に相対なので押し下げに追従する。問 N の刺さる場所に打つ。

### 時間軸・棒 (axis / dot / vline / hline / bars)

線と点だけを SVG に描く部品。文字は `note` で置く。押し下げの対象外 (箱が伸びても動かない) なので、軸の周りの `note` は軸と同じ行に揃える。

```
axis 12 70 340            ← y=70 に x 12→340 の軸 (右端に矢じり)
dot 60 70                 ← 出来事の点
vline 176 44 92 red       ← 区切り
note c 140 28 80 | !JST 0:00     ← ラベルは note
bars 14 70 7 2 18,12,22,10       ← x=14 から幅 7・間隔 2 の棒 (高さの列)。基線 y=70
```

### 例 (入れ子・曲線・折り返し)

```
node route 216 36 230 zone | Cloudflare のルート（ゾーン example.com）
node r1 228 62 206 in=route | `<slug>.lp.example.com/*`
  向き先: lp-<siteId> か lp-api
node api 520 140 184 red | lp-api（API Worker・D1）
  slug で D1 を 1 回引き
edge r1:r:0.8 -> api:l:0.3 red dashed curve "顧客ドメインが正のとき"
edge del:r -> build:l wrap noarrow
mark 1 r1 192 0
```

## seq — シーケンス図 (座標なし)

````
```seq <id> [w=360] [fs=10.5]
title: A. 再送するだけ
caption: A — 呼ぶ側は何も変えない
actors: 呼ぶ側, lp-api
呼ぶ側 -> lp-api: `POST /hostnames`
lp-api -> 呼ぶ側: 502（行は削除中で残る） | red
note lp-api: 残った行を先に片付ける | red
gap
lp-api -> 呼ぶ側: 201 | red dashed
```
````

- 参加者は等間隔の列。メッセージは上から順に流れる (高さは中身なり、被らない)
- `a -> b: 文 | フラグ` — フラグは `red` `dashed`。`` `…` `` で等幅
- `note <参加者>: 文 | red` — その列に置く箱。`gap` = 空行

## svg — 生 SVG (逃げ道)

````
```svg <id>
caption: 図 N — …
<svg viewBox="0 0 340 120">…</svg>
```
````

fig / seq で描けない図だけ。build が「生 SVG」の警告と、`<text>` の推定はみ出し本数を出す。1 行の文字数は `viewBox の幅 ÷ フォント px` を超えないように。

## shot — スクショ + 赤の overlay

````
```shot <id>
src: ./shots/settings.png        ← ソースからの相対パス (data URI に埋め込む) か https:// か data:
alt: 現行の設定画面
caption: 図 2 — ① が変更点
mark 1 20% 30% "① の変更"        ← 画像に対する % 座標。ラベルは任意
mark 2 60% 50%
```
````

既存画面に加える提案では現物のスクショが信頼の根。1.5MB を超える画像は警告 (縮小する)。

## 描けないもの

- 箱をよけて迂回する矢印 (経路は直線・L 字・コ の字・曲線・wrap の 5 種)。要るなら箱の配置で解く
- 横に並んだ箱の高さ揃え (行の押し下げは揃うが、箱そのものの高さは中身なり)
- 図の中の表 (表は Markdown の表として図の外に置く。強調行は `!`)
