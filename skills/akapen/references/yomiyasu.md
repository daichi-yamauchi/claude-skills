# 試問の前の文体直し (yomiyasu) — AI っぽい文を subagent に直させる

シートを書いた agent の文は、絵文字・比喩の動詞・否定対比・ダッシュ記号といった AI 特有の癖が残りやすい。
試問は「伝わるか」を見る検査で、文体の癖までは拾い切れない。そこで試問の前に、yomiyasu スキルを読み込んだ subagent にソースを直接書き直させる。メインに戻るのは直した箇所の要約だけなので、メインの文脈はほとんど増えない。

対象は標準モードのソース (`<topic>-<NN>.akapen.md`) だけ。chat の問いと、指摘・添削モードは対象外。yomiyasu が入っていない環境ではこの手順を飛ばす。

## 書き直してよい所と触らない所

| 書き直してよい | 触らない |
|---|---|
| `結論:` の文、節見出しの文言、説明の段落 | frontmatter 全体 |
| `用語:` の各行の定義文 (`—` の後ろ) | `用語:` の行そのものと、各行の語 (`—` の前) |
| fig / seq / shot の `title:` と `caption:` の値 | fig / seq / svg / shot の箱・矢印・mark の行、座標と id |
| `q` の 1 行目 (問い) と、各選択肢の案の名前・`利点:` `代償:` の値 | `q` の `A*` などの記号、区切りの `|`、`fig:` `根拠:` `数値:` の行 |
| `details` の中身 | `details` の見出しの書式、`==赤の注記==` と `~~取り消し線~~` の記号 |

yomiyasu の規則のうち、次の 4 つは akapen と衝突するので適用しない。

- 和文と英単語・数字の間の半角空白は残す
- 箇条書き (`用語:` の欄、選択肢の並び) を地の文にまとめない
- `用語:` `根拠:` などの行頭ラベルのコロンを消さない
- 見出しと本文を分ける `—` は残す。`用語:` の `語 — 定義` と、図の `title:` `caption:` の先頭の `図 1 — ` `A — ` `問 2-A — ` の形。消すのは文中のダッシュ記号だけ

## Agent ツールでの呼び方

`Agent` ツールで新しい subagent を立てる。`subagent_type` は general-purpose、`model` は `sonnet`。**同期で結果を待つ (background にしない)。** description は「<topic>-<NN> 文体直し（yomiyasu）[sonnet]」の形。prompt の雛形:

```
次の Markdown は、人に判断を求める「赤ペン」のシートのソースです。yomiyasu スキルの規則で、AI っぽい日本語を直接書き直してください。
ソース: /abs/path/to/akapen/<topic>-<NN>.akapen.md (Read で開き、Edit で直す)
規則: Skill ツールで yomiyasu を読み込む。使えなければ ~/.claude/skills/yomiyasu/SKILL.md と references/slop-catalog.md を Read する。どちらも無ければ何も直さず「yomiyasu なし」とだけ返す。ドメインは business。

書き直してよいのは、結論・節見出し・説明の段落・用語の定義文 (— の後ろ)・図の title と caption の値・q の問いと選択肢の案の名前・利点・代償の値・details の中身だけです。frontmatter、```fig などの図ブロックの箱・矢印・座標・id、q の記号 (A* と |)、fig: 根拠: 数値: の行は一字も変えないでください。
yomiyasu の規則のうち、次の 4 つは適用しないでください。和文と英単語・数字の間の半角空白は残す。箇条書きを地の文にまとめない。用語: 根拠: などの行頭ラベルのコロンを消さない。見出しと本文を分ける — (用語の「語 — 定義」、図の title と caption の先頭の「図 1 — 」「A — 」「問 2-A — 」) は残し、消すのは文中のダッシュ記号だけ。
原文にない事実・数値・理由を足さないでください。選択肢の意味が変わる書き直しはしないでください。

直し終えたら python3 "<skill>/assets/build.py" <ソース> --check を実行し、新しい警告が出たら自分の書き直しを戻してください。
出力は「直した箇所の数」と「直した種類 (比喩の動詞・否定対比・ダッシュ記号など) ごとの件数」だけ。本文の全文や差分は返さないでください。
```

## 受け取った後

- 「yomiyasu なし」なら何もせず試問に進む
- 要約を見て直しが多すぎる (問いの文がほぼ全部変わったなど) と感じたら、`git diff` か元の版との差分で問いの意味がずれていないかを自分で確かめる。ずれは次の試問の問い 1 でも拾える
- 再 build してから試問 (`references/preflight.md`) に進む。試問で直した後に、もう一度 yomiyasu を通さない
