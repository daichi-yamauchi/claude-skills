## ブロックの種類

| ブロック | 役割 | 詳細 |
|---|---|---|
| frontmatter | ラベル・日付・タイトル・読者宣言 | 上の例。`label` と `title` は必須 |
| `結論:` 段落 | 結論ボックス | 3 文以内。4 文以上で警告 |
| `用語:` + `- 語 — 定義` | 用語欄 | 読者が知らない語だけ。無ければ書かない |
| `## ` / `### ` | 節見出し | 主張型の文言で |
| 段落・箇条書き・表 | 説明 | 表は行頭 `!` で赤の強調行 |
| ```` ```fig <id> ```` | 箱と矢印の図 | `fig-dsl.md`。`w=360` 以下の図が連続すると横並び (`.ab`) になる |
| ```` ```seq <id> ```` | シーケンス図 | `fig-dsl.md`。座標なし |
| ```` ```svg <id> ```` | 生 SVG (逃げ道) | 警告が出る。文字のはみ出しは推定検査のみ |
| ```` ```shot <id> ```` | スクショ + 赤の overlay | `src:` の画像を data URI に埋め込む。`mark 1 20% 30% "① の変更"` |
| ```` ```q ```` | 問い | 下の節。判断材料と回答欄 (択一 / 保留 / 補足) を 1 枚のカードにする |
| ```` ```details <見出し> ```` | 畳み付録 | 見出しは中身と分量を予告する文言 (「詳細」「その他」は警告) |

ブロックはソースの順に並ぶ。骨格 (結論 → 用語 → 全体図 → 説明 → 対比表 → 問い → 畳み) は `sheet-rules.md` の順で書く。

## `q` ブロック

```
問 1. 問い 1 行                       ← 1 行目。「問 N.」は省略可 (番号は出現順で振り直す)
A* 案の名前 | 利点: … | 代償: … | fig: <図id>   ← 1 行 1 選択肢。英字 1 文字 + 推奨なら *。区切りは |
B  案の名前 | 利点: … | 代償: … | fig: <図id>
根拠: packages/…/index.ts:88 で …          ← 必須 (無いと警告)
数値: t.js 2KB、1 年キャッシュ             ← 任意
```

- `利点:` `代償:` `fig:` 以外の区切り要素は補足文としてそのまま載る
- `fig:` は fig ブロックで定義した図の id (定義の位置は q の前後どちらでもよい)。**参照された図は定義の位置には出ず、カードの選択肢の直下にだけ出る** (見て選ぶ場所に 1 回)。見た目の違う選択肢には必ず付け、方針・優先度の選択肢には付けない。参照されない図は定義の位置に出る (全体図・説明の図)
- 推奨 (`*`) は 1 つ。カードでは最初から選ばれた状態で出る。無いと警告 (人が全部自分で選ぶことになる)
- 非推奨の選択肢にも `利点:` を書く。無いと警告 (実質 1 択)
- カードには自動で選択肢のラジオ・「保留 — 決める前に聞きたいことがある」と質問欄・補足欄・「選択を解除 (未回答にする)」が付く。ソースには書かない。回答欄は各カードの中にあり、シート末尾に残るのは「全体への赤ペン」と [貼り付ける文章を作る] だけ
- 1 シート 4 問まで。5 問以上で警告

## 検査 (`--check`)

| 出るもの | 意味 |
|---|---|
| 警告: 問が N 問 | 5 問以上。次のラウンドか chat へ |
| 警告: 根拠: が無い | 事実を人に聞いていないか確認 |
| 警告: 推奨 (A*) が無い / 非推奨に利点が無い | ゲートとして機能しない問い |
| 警告: 箱 X が右端を超える | fig の `x + 幅` が図の幅を超えている |
| 警告: 生 SVG | ```svg を使った。文字のはみ出しは推定 |
| 警告: 結論が無い / 図が無い | 骨格の欠け |
| エラー: fig: X が無い / edge の X が無い / in= の zone が無い | 参照切れ。build が止まる |

## 再往復 (`-02`)
