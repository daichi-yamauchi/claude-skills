# 【赤ペン回答】固定形 — 3 モード共通の貼り戻し契約

人がブラウザの [貼り付ける文章を作る] を押すと、この形のテキストがクリップボードと textarea に出て、人が Claude Code のターミナルに貼って Enter する。agent はこの形だけを読む。
標準モードでは同じ返信に chat の問い (Q4〜 など) への答えが自由文で付く。それは通常の会話として読む。

## 形

```
【赤ペン回答】<label>
Q1. <質問>: A — <選択肢> / 補足: <自由記述>
Q2. <質問>: (未回答 = 保留)
Q3. <質問>: (保留) 質問: <人が聞きたいこと>
全体への赤ペン: <自由記述 (複数行あり得る)>
## 指摘
#12 [短くする] <ひとこと>
#15 [ここは良い]
## 添削
- 段落 3: 「旧の語」→「新の語」
- 段落 7: (削除)
```markdown
<完成形 Markdown 全文>
```
---
上の回答を反映して作業を続けてください。未回答と保留の項目は推奨で確定せず、保留の質問に答えてから次の往復で聞き直してください。
```

## 規則

- 1 行目 `【赤ペン回答】<label>` と末尾の `---` + 締めの 1 文は **全モード必須・不変**
- 旧シート (2026-09-25 より前に build したもの) は `(未選択 = お任せ)` と「お任せの項目は推奨案で確定」を出す。人は未回答のつもりでいる可能性があるので、推奨で確定せず未回答と同じく再掲する
- `Qn. <質問>: A — <選択肢> / 補足: <自由記述>` — 標準モードの択一。補足が空なら ` / 補足:` を省く
- シートは推奨の選択肢を**選んだ状態で出す**。人が推奨のまま返せば `A — <選択肢>` の行になり、それで確定する
- `Qn. <質問>: (未回答 = 保留)` — 人が選択を解除した問い。**推奨で確定しない。** 質問の無い保留として扱い、次のラウンドのシートか chat に再掲する
- `Qn. <質問>: (保留) 質問: <text>` — **推奨で確定しない。** agent はその場で質問に答え、次のラウンドのシートか chat に同じ問いを再掲する。`(未記入 — …)` なら「何を聞きたいか」を chat で聞き返す
- `全体への赤ペン:` — 自由記述。次の見出し (`## `) か `---` までが本文。`(なし)` は空
- `## 指摘` — 指摘モードのみ。`#<ブロック番号> [<チップ>] <ひとこと>`。チップだけの行もある。ブロック番号は原稿の DOM 順 (`data-blk`)
- `## 添削` — 添削モードのみ。語単位の差分行を段落ごとに並べ、その後に完成形 Markdown の全文をコードブロックで載せる
- 空の節は出さない (指摘 0 件なら `## 指摘` 自体を出さない)
- テンプレ (`assets/sheet.js`、shiteki / tensaku の script) を改造するときもこの形を崩さない

## chat の問いへの返信ひな形

chat の問い (❓) には、推奨で埋めた返信ひな形を 1 つのコードブロックで添える。人は変える行だけ書き換えて返す。

```
Q4. <見出し>: <推奨案>
Q5. <見出し>: <推奨案>
```

読み方:

- 推奨案のまま返った行 → 推奨で確定
- 書き換えた行 → その内容で確定
- `Qn. <見出し>: 保留 <聞きたいこと>` → 保留。その場で答えて再掲する
- **行を消した・返信で触れなかった問い → 未回答 = 保留。** 推奨で確定しない
- ひな形を使わず自由文で答えてきた場合も同じ。言及のあった問いだけ確定し、残りは未回答として再掲する
